## Featured Projects

### AUS CPI-WPI

Analysis of Australian Consumer Price Index (CPI) and Wage Price Index (WPI) data from the Australian Bureau of Statistics.

**What it covers:**
- Retrieving data from the ABS API
- Storing and querying structured data in MySQL
- Data transformation and analysis with Pandas
- Calculating year-on-year inflation and wage growth
- Comparing wage growth against inflation
- Visualising trends with Matplotlib

**Technologies:**  
Python, Pandas, Requests, SQLAlchemy, MySQL, Matplotlib, Git

[View Project](https://github.com/khristianie/aus-cpi-wpi)
